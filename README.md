# Skyline Sprint

A browser-based 3D endless runner. Open `index.html` through a local web server or upload `index.html` and `game.js` together to a static web host. The game loads Three.js from jsDelivr, so players need an internet connection.

## Publish a public website

1. Extract the ZIP on your computer.
2. Open https://app.netlify.com/drop in a browser and sign in or create a free Netlify account if prompted.
3. Drag the extracted folder containing `index.html` and `game.js` into the drop area.
4. Netlify gives you a public `*.netlify.app` URL. Open that link in Chrome or share it with friends.
5. To place it in Google Sites, add an Embed block and enter the public Netlify URL. Chrome is the browser that opens the site; it does not host websites.

Keep `index.html` and `game.js` together in the uploaded folder. The local preview address (`127.0.0.1`) only works on this computer and is not the public link.
